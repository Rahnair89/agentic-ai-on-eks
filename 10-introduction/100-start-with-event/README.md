# 100 · Start with AWS Event

> Workshop section: [Start with AWS Event](https://catalog.workshops.aws/ai-agents-on-eks/en-US/10-introduction/100-start-with-event)

The workshop runs in a pre-configured AWS account issued through AWS Workshop Studio. The account
arrives with the infrastructure and IAM policies the labs need already in place, so no provisioning
happens by hand.

## Access path

1. Open the Workshop Studio link from the event host.
2. Choose **Email One-Time Password (OTP)** as the sign-in method.
3. Enter your email and the 9-digit event access code; a passcode arrives by email.
4. Accept the terms on the Review and Join page and join the event.

The temporary account is then reachable from the Event Dashboard.

## Worth knowing

The account is ephemeral and AWS-owned. Nothing you create in it survives the event, and the terms
prohibit putting real personal or business data into it — the labs run entirely on the fictional
AnyCompany Shop dataset for that reason.

Log out of other AWS accounts in the browser before opening the temporary one. Session collisions
between a personal console session and the workshop account are the most common first-five-minutes
failure.
